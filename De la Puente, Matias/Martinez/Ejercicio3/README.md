#Ejercicio 3 - API de Tareas

##Descripción
Este proyecto implementa una **API REST con ExpressJS** para administrar tareas y su estado de avance.  
Cada tarea cuenta con un **nombre único** y un **estado booleano** que indica si fue completada.  
La API permite diferenciar entre tareas completadas y pendientes, asegurando la unicidad de nombres y respuestas claras en formato JSON.

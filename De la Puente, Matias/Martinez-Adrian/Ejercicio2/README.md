#Ejercicio 2 - Peticiones HTTP

##Descripción
Este ejercicio implementa un servidor en **Node.js con ExpressJS** que expone distintos **endpoints HTTP** para practicar el envío y recepción de solicitudes.  
El objetivo es comprender cómo funcionan las **peticiones GET y POST**, cómo se validan parámetros y cómo se estructuran las respuestas.
